# Lottie Developer — рабочая папка дизайнера

Здесь дизайнер вместе с Claude делает Lottie-анимации в приложении **Lottie Developer**.
Результат работы — Lottie JSON, совместимый с lottie-ios, который дизайнер отдаёт разработчику.

## Кто что делает

| Кто | Что делает |
|---|---|
| Дизайнер | даёт ассеты (zip, папка, SVG, PNG) и пишет, что должно двигаться; смотрит результат в приложении; оставляет комментарии на кадрах |
| Claude | через MCP `lottie-developer` собирает сцену, делает версии, проверяет рендером, читает комментарии, исправляет |
| Приложение | показывает всё сразу: таймлайн, слои, версии, ассеты, комментарии, экспорт |

## Порядок работы

Подробно — скилл `/animate`. Коротко:

1. **Ассеты.** zip или папка → `create_project(bundle: путь)`. Файлы, которые дизайнер положил во вкладку Assets, — `list_assets`, `place_asset`.
   Картинку, вставленную в чат скриншотом, в файл сохранить нельзя: попроси перетащить сам файл в чат.
2. **Сцена.** `render_frame` → посмотри картинку сам → `place_layer`, `rename_layer`, пока раскладка не совпадёт с макетом.
3. **Движение.** `get_guide` → `validate_spec` → `create_version` с `prompt` (задумка) и `note` (что сделал).
4. **Проверка.** `render_frame(count: 8)` и посмотри кадры. Без рендера не говори «готово».
5. **Комментарии.** `get_feedback` → исправь → `resolve_feedback` с коротким ответом.
6. **Сдача.** Финальная версия → `export` в JSON (или Export в приложении). Отдай дизайнеру путь к файлу.

## Правила

- Ничего не удаляй (проекты, версии, ассеты) без явной просьбы. Откат — `restore_version`.
- Каждая версия — с `note` одной строкой: что поменялось.
- Импортированные слои называются `path-3`, `rect-2` — переименуй значимые до анимации.
- Слои-картинки (растр, SVG с blur/масками) двигаются только трансформами: fade, slide, scale, rotate, followPath.
- Группа (слой с именем файла) двигает все свои части.
- `show_in_app` с `frame` и `layer` — показать дизайнеру конкретный момент.
- С дизайнером — простыми словами, без внутренних терминов (spec, null-слой).

## Если инструментов `lottie-developer` нет

Попроси дизайнера: открыть Lottie Developer → кнопка **Set up Claude…** → перезапустить сессию Claude в этой папке и подтвердить сервер `lottie-developer`.
