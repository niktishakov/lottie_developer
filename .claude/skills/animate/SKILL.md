# /animate — цикл работы с дизайнером

Инструменты: MCP `lottie-developer` (если их нет — `bin/lottie-mcp --build` и перезапустить сессию).

## 0. Понять задачу
- Есть ли проект? `list_projects` / `get_app_state` (что дизайнер сейчас смотрит).
- Есть комментарии? `get_feedback` — если да, начинай с них (шаг 5).
- Промт непонятен (что двигается, порядок, длительность) — задай 1–3 вопроса списком. Не угадывай длительность: по умолчанию 2 с.

## 1. Ассеты → сцена
| Что дали | Вызов |
|---|---|
| zip / папка | `create_project(bundle: "<path>")` |
| набор PNG | `create_project(images: [...])` (первая — верхний слой) |
| SVG в существующую сцену | `add_svg(path, x, y)` |
| картинка в сцену | `add_image(path, x, y, width, height)` |
| файлы уже в проекте (дизайнер положил в Assets) | `list_assets` → посмотри файлы по `path` → `place_asset(name, x, y)` |
| добавить файлы в папку проекта без сцены | `add_assets(paths)` |
| скриншот в чате | попроси файл: в файл его не сохранить |

Сразу: `render_frame(size: 500)` и **посмотри**. Сравни с макетом/описанием. Чини раскладку `place_layer` (группе — x, y, scale; картинке — точный прямоугольник; `z` — порядок).
Переименуй значимые слои (`rename_layer`): `path-7` → `shield`. Покажи дизайнеру `show_in_app`.

## 2. Движение
- `get_guide` один раз за сессию — там схема AnimationSpec и список приёмов.
- Пиши spec: тайминг в секундах, 60 fps, stagger 0.05–0.15 с, входы `easeOut`/`easeOutBack`.
- `validate_spec` → `create_version(prompt: "<задумка>", note: "<что сделал>")`.
- Нужен точный контроль (своя кривая, несколько ключей, конкретные значения) → `set_keyframes` поверх версии.

## 3. Проверка (обязательно)
- `render_frame(version: "latest", count: 8)` — посмотри все кадры: начало, пик, конец, нет ли пропавших слоёв, выходов за кадр, рывков.
- Не так — исправь и сделай новую версию. Старые не удаляй.

## 4. Отчёт дизайнеру
Коротко: что сделано (версия vN), где смотреть (`show_in_app` на ключевом кадре), что осталось/вопросы. Таблица, если пунктов больше двух.

## 5. Комментарии
- `get_feedback(status: "open")` → по каждому: понять (версия, кадр, слой, текст), исправить в новой версии.
- `resolve_feedback(id, reply: "сделал в v5: …")`. Не отмечай решённым то, что не проверил рендером.

## Подсказки
- Группа (импортированный SVG) двигает все свои части; отдельная часть — по своему имени.
- Слой-картинка: только трансформы (fade/slide/scale/rotate/spin/float/followPath…).
- Откат: `restore_version`. Сравнение: `diff_versions`.
- Экспорт: `export(path)` — JSON; `.lottie`/GIF — в приложении (Export).
