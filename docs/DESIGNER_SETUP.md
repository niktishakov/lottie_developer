# Lottie Developer — как начать

Нужно: Mac (macOS 14+) и Claude (приложение Claude для Mac с вкладкой Code, или Claude Code в терминале). Xcode не нужен.

## 1. Установить приложение

1. Открой DMG и перетащи **Lottie Developer** в **Applications**.
2. Запусти его из Applications. macOS скажет, что не может проверить разработчика, — нажми **Готово**.
3. Открой **Системные настройки → Конфиденциальность и безопасность**, внизу у «Lottie Developer» нажми **Всё равно открыть** и подтверди.
   Это нужно сделать один раз.

## 2. Подключить Claude

1. В Lottie Developer на экране Projects нажми **Set up Claude…** и выбери папку (по умолчанию `Документы/Lottie Workspace`).
2. Открой эту папку в Claude:
   - приложение Claude → вкладка **Code** → новая сессия → выбери папку;
   - или в Терминале: `cd ~/Documents/Lottie\ Workspace` и `claude`.
3. Когда Claude спросит про сервер **lottie-developer** — разреши.
4. Проверь: напиши Claude «покажи мои проекты».

Lottie Developer держи открытым — всё, что делает Claude, появляется в нём сразу.

## 3. Работа

| Что хочешь | Что сделать |
|---|---|
| Начать новую анимацию | перетащи zip / папку с ассетами в окно Projects или в чат Claude и опиши, что должно двигаться |
| Докинуть ассеты | вкладка **Assets** в проекте: перетащи файлы, или кнопка Folder и положи файлы туда |
| Попросить правку | напиши Claude в чат, или поставь комментарий на кадре: вкладка **Comments** (пауза на нужном кадре, выбери слой, напиши) |
| Сравнить версии | **Compare** над превью |
| Поправить самой | инспектор справа: цвет, прозрачность, скрыть слой → **Save edits as new version** |
| Отдать результат | попроси Claude «экспортируй финальную версию», или **Export → Lottie JSON…** |

Обычный цикл: ассеты и задача → Claude делает версию → смотришь в приложении → комментарий или сообщение → новая версия → экспорт JSON разработчику.

## Если что-то не так

| Проблема | Решение |
|---|---|
| Claude не видит инструменты lottie-developer | Lottie Developer → **Set up Claude…** ещё раз, перезапусти сессию Claude в этой папке |
| Перенесла приложение в другое место | запусти его один раз — папка для Claude обновится сама |
| Изменения не появляются в приложении | проверь, что приложение открыто; открой проект заново |
