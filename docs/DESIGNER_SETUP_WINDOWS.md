# Lottie Developer для Windows — как начать

Нужно: Windows 10/11 x64 и Claude Code (приложение Claude → вкладка **Code**, или Claude Code в терминале).
Ничего больше ставить не нужно: всё в одном файле `lottie-developer.exe`.

## 1. Положить файл

1. Создай папку `C:\Tools` и положи туда `lottie-developer.exe`.
2. Дважды кликни по нему один раз. Windows покажет «Windows защитила ваш компьютер» — нажми **Подробнее → Выполнить в любом случае**.
   Откроется браузер с пустым списком проектов — значит, всё работает. Окно можно закрыть.

## 2. Подключить Claude

Напиши в Claude Code — он сделает сам:

```
Подключи MCP-сервер Lottie Developer для всех сессий:
claude mcp add -s user lottie-developer -- C:\Tools\lottie-developer.exe
```

Начни **новую сессию** и напиши «открой просмотрщик и покажи мои проекты». Если Claude спросит про сервер **lottie-developer** — разреши.

## 3. Работа

Claude открывает просмотрщик в браузере: `http://127.0.0.1:7357`. Держи вкладку открытой — всё, что делает Claude, появляется там само.

| Что хочешь | Что сделать |
|---|---|
| Начать анимацию | перетащи zip / папку / файлы в чат Claude и опиши, что должно двигаться |
| Посмотреть | в просмотрщике: проигрывание, пауза, кадры, скорость, фон, версии справа |
| Попросить правку | напиши Claude, что поменять (можно с номером кадра — он виден под плеером) |
| Отдать результат | «экспортируй финальную версию в JSON на рабочий стол» → пришли файл разработчику |

## Если что-то не так

| Проблема | Решение |
|---|---|
| Claude не видит инструменты lottie-developer | новая сессия Claude; не помогло — попроси выполнить команду из шага 2 ещё раз |
| Просмотрщик не открывается | попроси Claude «открой просмотрщик» или открой `http://127.0.0.1:7357` вручную (Claude должен быть запущен) |
| Антивирус удалил exe | добавь `C:\Tools\lottie-developer.exe` в исключения и скачай заново |

Проекты хранятся в `%APPDATA%\LottieDeveloper\projects`.
